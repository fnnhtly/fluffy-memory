# 美术方案 · 滚蛋吧！猪（垂直切片）

> 方向（用户 2026-04-19 定）：**画风结合——优先官方素材造景产生 3D 感，交互物与 UI 用图元。**
> 实测结论（`docs/art-catalog.md` + `docs/art/official-image-as-sky-failure.png`）：
> ① 官方 imageId 里**没有**任何场景贴图；
> ② 连"拿官方底纹当天空"也不成立——底纹都是**带花纹边框的卡片**，拉成全屏会变成巨大的雕花画框。
> 因此最终定案：**造景 100% 用图元 + 原神调色**，官方素材只用于 **UI 图标与卡片面板（原生尺寸）**。
> 用户 2026-04-19 选定：**更原神一点**。

## 一、三条美术原则

1. **近景实、远景虚**：离玩家越近，对比度越高、颜色越饱和、描边越重；远处压低对比并加雾。
2. **交互物必须"可读"**：车体零件、木箱、终点旗一律用图元 + 高饱和色 + 深色描边，任何背景都不能让它们糊掉。
3. **UI 用官方图标，场景用图元**：官方图标 = 对勾/垃圾桶/宝箱/齿轮/星级/评级；场景 = 图元分层。

## 二、四层景深（3D 感的来源）

| 层 | 内容 | 实现 | 视差 | 处理 |
|---|---|---|---|---|
| L1 天空 | 黄绿渐变到地平线 | 官方底纹 **107231**（星空蓝紫）或 **106072**（浅蓝花纹）染色，或两层图元渐变 | 0.1× | 最亮、最低对比 |
| L2 远山/丛林 | 圆冠 + 棕榈剪影 | 图元（rect 圆冠 + 三角/斜条叶） | 0.35× | 压暗 20%、加雾、颜色偏冷 |
| L3 地形 | 石墙 + 草皮 | 图元条带：主色 → 上沿高光 → 下沿暗部 → 草皮亮带 → 重描边 | 1.0× | 最实，描边最重 |
| L4 前景 | 沙滩 / 海水 / 浪花 / 雾带 | 图元（横向色带 + 正弦浪花线 + 泡沫点） | 1.3× | 更亮/更饱和，压住地形底部 |

**3D 感不是靠贴图，是靠这 6 个手段**：

1. **明暗**：所有体积都有「上亮下暗」（草皮顶亮线、石墙上沿高光、坑底压暗）；
2. **遮挡**：前景色带压住地形底部；车体压住阴影；
3. **透视缩放**：远景层元素按 0.6~0.8 缩放；
4. **接触阴影**：车/零件/木箱下方一个压扁的半透明椭圆；
5. **雾**：远景层与地形之间一条 8%~12% 高度的半透明白/灰带；
6. **色温**：近景偏暖（黄绿），远景偏冷（蓝绿）。

## 四、零件与交互物的图元语言

约定：**形状表示类别，颜色表示具体零件，缺口/轮廓表示朝向**。

| 零件 | 图元组合 | 读出信息 |
|---|---|---|
| 木框 | **四条边围成中空方框**（内壁描阴影）+ 对角两名挂点铆钉 | 唯一可挂载的结构件；中间是空的、能透出后面的景，是 3D 感来源之一 |
| 木轮 / 铁轮 | circle 实心 + 内圈轮毂 + 高光弧 | 轮径 = 越障能力 |
| 马达 | rect（红）+ 小方块出轴 | 持续动力 |
| **方向件（打气筒/风扇/螺旋桨…）** | 零件本体 + **零件本色箭头**（深色打底/白包边/实心三角，伸出格子 1 格） | 喷气方向；悬停额外标「上/下/左/右」；**同色 = 同组**，行驶时底部一个同色按钮控制全组 |
| 电池 | rect（绿）+ 闪电三角 | 能量 |
| 打气筒 | 竖 rect（蓝）+ 顶部横条活塞 | **手动交互件**（会变成按钮） |
| TNT（P1） | rect（暗红）+ 引线 | 一次性爆发 |
| 木箱 | 官方 **105221**（木箱）/ **105222**（宝箱） | ★★ 收集物 |
| 终点旗 | rect 杆 + 三角旗 | 终点 |
| 猪 | circle + 双耳 + 鼻子；受伤 → × 眼 | **放进木框里**（0.62 倍），是玩家要保护的对象 |

## 六、与 HTML 演示的映射（步骤 3 → 步骤 5）

HTML 里用 Canvas 自绘的东西，到千星全部要落成"图元 / 官方图 / 文本"三种：

| HTML 里的画法 | 千星落法 |
|---|---|
| 渐变天空（`createLinearGradient`） | 3~4 条不同颜色的横条 rect 叠出渐变（或官方底纹染色） |
| 石墙砖纹（循环画圆角块） | 用 5~8 条竖条 + 2 条色带（高光/暗部）近似；砖纹本身放弃 |
| 棕榈（二次曲线） | 三角图元当叶子 + 细 rect 当树干（旋转拼） |
| 浪花（正弦线） | 一排半透明圆点 + 一条亮色横带 |
| 猪（ellipse + 小圆） | circle + 两个小 circle 耳朵 + 小 rect 鼻子 |
| 接触阴影 | 一个压扁的深色 circle（`localScale.y` 压到 0.3） |
| 粒子/碎片 | P1 再做（图元池里临时取 8~12 个 rect 做抛物线） |

## 七、本步结论：哪些能做、哪些放弃

- **能做**：4 层景深 + 6 种 3D 手段 + 图元零件语言 + 官方图标 UI；
- **放弃**：石头砖纹细节、棕榈的真实叶形、海面波浪形状、手写卡通字体、录音音效；
- **理由**：千星只能显示 6 种图元（且模拟器只预览这 6 种）+ 官方 UI 图；
  这些细节超出表达力，硬做只会得到"糊成一片"的画面。

## 八、给用户的确认项

1. 这套"图元分层 + 官方 UI 图标"的方向是否可以？
2. 天空底用官方 **107231（星空蓝紫）** 还是保持黄绿渐变（纯图元）？
   —— 前者更"原神"，后者更"捣蛋猪"。
3. 是否同意把 UI 图标全部换成官方 imageId（对勾/垃圾桶/宝箱/齿轮）？

## 九、官方素材的**正确用法**（这一步的最终结论）

| 用法 | 可行 | 说明 |
|---|---|---|
| 铺满屏幕当天空/远景 | ❌ | 官方底纹都是带边框的卡片，拉满会变成巨大画框（见 `art/official-image-as-sky-failure.png`） |
| 当 HUD/结算面板的底（原生尺寸） | ✅ | 例如 107208 / 107183 / 107032，放在原生大小最好看 |
| 当 UI 图标（对勾/垃圾桶/宝箱/齿轮/星级/评级） | ✅✅ | 这是官方素材最大价值，比自绘图元清晰 |
| 当零件/车的贴图 | ❌ | 没有对应素材；零件继续用图元 + 染色 |
| 当环境装饰（冰块/岩石/云） | ⚠️ | 只能借用图标（如 105269 云、104001 星）染色缩小当装饰，别指望像场景 |

**结论**：原神感来自**调色 + 金色细边 + 官方图标**，不来自场景贴图。
