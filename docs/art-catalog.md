## 二、能用的部分（按用途）

### 造景（能做"3D 感底子"的少数几张）

| 用途 | imageId | 实测外观 |
|---|---|---|
| 天空/远景底 | **107231** | 星空蓝紫渐变（最像"远景色"的一张） |
| 天空/浅色底 | **106072** | 浅蓝带花纹的底纹 |
| 远景/水面底 | **107002** | 蓝白竖向渐变 |
| 远景/雾 | **106050** | 深蓝夜景底 |

## 三、给实现的三条硬结论

1. **"优先官方素材造景"在千星里不成立**——没有场景素材可优先。能做的只有"官方底纹当背景层 + 图元造景"。
2. 真正的 3D 感只能靠**图元分层**：视差 + 明暗 + 遮挡 + 透视缩放 + 接触阴影 + 雾。
   具体配方见 `docs/art-bible.md`。
3. UI 建议**换成官方图标**（对勾/垃圾桶/宝箱/齿轮/星级/评级）——这是花最小代价获得"官方质感"的地方，
   而且比自绘图元更清晰。
