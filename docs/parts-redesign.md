## 1. 捣蛋猪的机制骨架（从资料里抄的，不是猜的）

### 1.1 动力是"三件套"，不是"一个马达"

| 类别 | 件 | 语义 |
|---|---|---|
| **永久动力源** | 电机（绿）/ 柴油（棕）/ 涡轮（红）/ 核 | **必须放在框子里**。只提供"动力容量"，自己不产生推力 |
| **驱动工具** | 小螺旋桨 / 大螺旋桨 / 电风扇 / 黄伞 | **消耗动力容量**产生推力/升力。必须和动力源**连通**（中间要有连接件） |
| **一次性动力源** | 雪碧/可乐（短）、红/蓝火箭（长）、TNT | 点一次喷完就没了。**不需要连通**，自己就推 |
| **手动工具** | 气阀 / 黑伞 / 拳套盒 / 吸盘枪 | **完全不耗动力**，玩家按才动 |

这是"马达 + 电池"最根本区别：**动力源和推力件是两件东西，中间靠连通性耦合**。
参考里的原话："除了雀斑猪外，必须放在木框或者铁框里"、
"只要中间有动力连接件（框/可乐/火箭/分离器/弹簧都算，绳子不算），动力可以叠加"。

所以"马达"这个词在参考里**不存在**。存在的是「动力源」+「螺旋桨」。
我们现在的 `motor`（自带推力 + 自带 12 电量 + 靠电池扩容）是这两者的错误合并。

### 1.2 浮力是"一对"，不是"一个气球"

原话：

- 气球："升力小于载具的总重则会『抵消』一部分重力"、
  "碰到墙壁或地面会自动破裂，除此以外玩家也可以手动爆破气球"
- 重物（沙包）："使载具增重"、"游戏进行期间玩家可以手动卸载悬挂的重物"
- **关键布阵规则**："如果某格放置有气球，则开始游戏后，气球会被系在其下方
  最靠近自身的方框上；否则气球会直接飘走"、
  "如果某格放置了重物，则重物会系在其上方最接近自身的方框上；否则重物会直接落地"

这条"系在哪"是**布阵阶段的物理约束**，我们现在完全没有。
我们的气球是"格子里一个圆，浮力直接加到车心"，沙袋是"格子里一个袋，质量加到车心" ——
位置无关。而参考里位置决定生死：气球没系到框上就飞了。

## 2. 原神地域皮肤（用户给的方向）

用户点名了两个例子：「蒙德可以做热气球，璃月可以做仙术机关」。
按这个思路把七国各自的"技术基调"排出来，每一样都要**对应一个真实机制**，
不能只是换皮：

| 地区 | 技术基调 | 映射到哪个机制 |
|---|---|---|
| **蒙德**（风） | 风车、滑翔翼、热气球 | 浮力（气球→热气球）+ 升力面 |
| **璃月**（岩/仙术） | 机关术、归终机、仙家法宝 | **动力源**（"仙力"）+ 钟离的岩柱（结构） |
| **稻妻**（雷） | 雷楔、御影炉心 | 一次性大推力（雷楔/火箭） |
| **须弥**（草/智慧） | 虚空终端、遗迹机械 | 逻辑门/顺序控制 |
| **枫丹**（水/蒸汽） | 蒸汽机、机械齿轮 | 持续动力 + 传动 |
| **纳塔**（火） | 燃素、翼龙 | 一次性燃料 + 冲刺 |
| **至冬**（冰） | 愚人众机械、冰面 | 抓地力（冰面轮） |

## 3. 重做方案（待实现）

### 3.1 新的零件表

把「动力源 / 驱动工具 / 一次性推力 / 手动工具 / 浮力配重」分成五类，
每类至少两件，每件带一个地区皮肤：

| id | 名字（地区） | 类别 | 机制 |
|---|---|---|---|
| `wood_frame` | 木框 | 结构 | 不变（中空、可塞东西） |
| `iron_frame` | 铁框（璃月·岩） | 结构 | 更重更结实 |
| `wood_wheel` | 木轮 | 轮 | 不变 |
| `iron_wheel` | 铁轮 | 轮 | 不变 |
| `anemo_core` | 风种（蒙德） | **动力源** | 提供 `power` 容量，必须放框里 |
| `geo_core` | 岩种（璃月） | **动力源** | 容量更大、更重 |
| `propeller` | 风车桨（蒙德） | **驱动工具** | 消耗 power 产生推力，方向可转 |
| `balloon` | 热气球（蒙德） | 浮力 | 必须**系在框下方**，否则飘走 |
| `sandbag` | 压舱石 | 配重 | 必须**系在框上方**，否则落地 |
| `firework` | 霄灯（璃月） | 一次性推力 | 点一次，向上推一段就烧完 |
| `pump` | 仙术机关（璃月） | 手动工具 | 不耗 power，按才动 |
| `pig` | 小猪 | 载荷 | 不变 |

### 3.2 必须落实的三条参考语义

1. **动力连通性**：驱动工具必须通过结构件连到动力源，否则不转。
   这条要能在 HUD 上看见（"这台螺旋桨没连上动力"）。
2. **气球系在框下方 / 沙袋系在框上方**：布阵阶段就校验，
   非法摆放要么禁止、要么在出发时视觉上"飘走/落地"。
3. **一次性推力烧完就没**：霄灯点一次，喷 1.2 秒，然后变成空壳。

### 3.3 不做

- 弹簧/绳子/分离器（四色）：参考里它们主要服务于"弹簧飞刀"这类 BUG 玩法，
  在 2D 单刚体模型里做不出可信行为。
- 机翼/尾翼：二维横版没有真正的气动，做了就是假物理。
- 吸盘枪：8 方向放置 + 攀爬，超出本轮。

### 5.2 三个机制落地在哪

- **动力连通**：`powerGrid(build)` 做 BFS，只有结构件导电。
  驱动件没接通就是 `powered=false`，一点推力都不给。
  "接通但超载"是**另一个**失败（`power_short`），HUD 会写「差 2 点动力」。
- **系挂**：`tetherCheck(build, r, c, kind)`。气球往 row 增大方向找框、
  沙袋往 row 减小方向找。找不到就是没系住 → 气球不给浮力、沙袋不计入可扔。
- **一次性推力**：`p.def.oneShot`，点车身点火，`p.burn` 记 1.2 秒，
  `step` 里按 `burn > 0` 出推力。它**不参与** powerGrid。

### 5.3 计划之外踩到的（都已修，记下来免得重犯）

| 现象 | 根因 | 谁抓到的 |
|---|---|---|
| 1-3 标准解翻了 180° 躺平 | 驱动件的力矩按真实位置算，一格 = 1 米，等于撬棍 | `dbg_1_3_r63.js` 逐帧看姿态 |
| 1-3/1-4 装不上 | 风种和猪都要"放框里"，一格只能塞一件 | `test_specs_r63` 报 `reason=pig` |
| 1-3 标准解卡在 x=7.3 | 风车桨 5.0 m/s²，而某段地形吃掉了初速；实测转速到顶 | 逐帧 trace |
| 1-4 爬不上 0.44 的冰坡 | 沿坡重力 6.44 m/s² > 风车桨 5.0。**算出来的**，不是试的 | 手算 + 实测 x=11.98 停住 |
| 1-6 完全不动 | 气球**只给垂直力**，起点平坦时没有水平分量 | 逐帧看 x 从 1.50 到 1.60 就停 |
| 1-6 赢了但没飞 | 只判 `win` 不判轨迹，风车桨把它推过去了 | 加 `peak > 终点地表 + 0.8` |
| 整页白屏 | `batteryPctOf` 删了但渲染循环还在调 → `ReferenceError` | `dbg_page_init.js` |
| HUD 显示「能量 NaN」 | 同一批删字段留下的读空 | 真机截图 + `audit_dead_reads` |
