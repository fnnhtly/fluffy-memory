| 维度 | 像不像 | 说明 |
|---|---|---|
| 玩法与流程 | **~90%** | 造车→发射→物理→三星→一秒重开全流程一致；交互件即键位同一套思路 |
| 界面结构 | **~80%** | 蓝垃圾桶/蓝对勾/绿重开/左上红暂停/右上计时/底部零件槽+数量/底部中间浅绿交互键 —— 位置语义都对上 |

| 场景美术 | **~60%** | 已补：**棕榈剪影**、**沙滩 + 海水 + 白浪**、石墙砖纹 + 草皮重描边 |

## 四、平台上限（必须先定）

HTML 能画到"像 Bad Piggies"，**千星真机不能照搬**：客户端控件只能显示
**官方 imageId** 或 **100001–100006 六种图元**，没有 Canvas 自绘、没有运行时绘制 API。

所以步骤 4 之前必须二选一：

1. **接受图元风**（圆/方/三角 + 染色 + 旋转）：上面 1~4 项还能逼近，5~7 项基本放弃；
2. **找官方素材**：去编辑器素材库确认有没有草地/岩石/海水/棕榈/猪的 imageId，有则按 ID 还原。
